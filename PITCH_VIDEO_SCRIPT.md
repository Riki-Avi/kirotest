# Guion Oficial para el Video de Presentación (Pitch de 5 Minutos)

Este documento detalla la estructura y el guion recomendado para la grabación del video de presentación del proyecto **Kiro Code Lab** requerido por la Sección 6 y 8 del Reglamento del Hackathon.

---

## Estructura General del Video (Duración Total: 4:30 a 5:00 minutos)

- **0:00 - 0:45 | Introducción y Problema (45 segundos)**
  - Presentación del equipo y del proyecto Kiro Code Lab.
  - Explicación del problema: La deserción en el aprendizaje de programación debido a errores no guiados y falta de retroalimentación en tiempo real.

- **0:45 - 1:30 | La Solución e Impacto (45 segundos)**
  - Presentación de Kiro Code Lab: Una plataforma web interactiva con Monaco Editor, tutoría socrática con IA y sintetizador de audio de foco.
  - Explicación de cómo Kiro impulsó el desarrollo del proyecto.

- **1:30 - 3:30 | Demostración Funcional en Vivo (2 minutos)**
  - Selección de un ejercicio algorítmico (ejemplo: Suma de Elementos o Palíndromo).
  - Demostración de cambio de lenguaje en tiempo real (C#, Java, TypeScript).
  - Ejecución de código y corrida de suite de pruebas con Judge0.
  - Interacción con el Tutor IA Socrático probando los 3 modos de intensidad (Conciso, Normal, Detallado).
  - Activación de la Zona de Foco con Ruido Marrón.
  - Guardado de la solución en el perfil del usuario.

- **3:30 - 4:15 | Arquitectura y Uso de AWS / Kiro (45 segundos)**
  - Explicación rápida del stack tecnológico: ASP.NET Core 10, Judge0 API, Gemini API, Web Audio API y Docker.
  - Explicación de la infraestructura en AWS (App Runner / ECS).

- **4:15 - 4:50 | Conclusión y Cierre (35 segundos)**
  - Resumen del valor educativo y potencial de escalabilidad.
  - Agradecimientos a Código Facilito y AWS.

---

## Recomendaciones Técnicas para la Grabación

1. **Resolución**: Grabar a 1080p a 60fps.
2. **Audio**: Asegurar micrófono claro y sin ruido de fondo.
3. **Privacidad**: Mostrar únicamente el código del proyecto sin exponer API Keys ni credenciales sensibles.
4. **Formato**: Subir a YouTube en modo Oculto o Público y adjuntar el enlace en el formulario de entrega.
